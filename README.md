# #️⃣Jogo da Velha

O Jogo da Velha é uma aplicação interativa para dois jogadores, em que cada jogador deve marcar espaços no tabuleiro e tentar formar uma sequência de três símbolos iguais.

## Funcionalidades

- Tabuleiro interativo
- Alternância entre jogadores
- Identificação do vencedor
- Identificação de empate
- Reinício da partida

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
